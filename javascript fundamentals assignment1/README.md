# JavaScript Fundamentals Assignment

This folder contains beginner-friendly solutions to all 14 questions in the assignment.

## Files
- `question1.js` through `question14.js`: one JavaScript file for each question.
- Each file includes comments and console output statements.

## How to run
1. Open this folder in Visual Studio Code.
2. Open a terminal in the folder.
3. Run a question with Node.js, for example:

```bash
node question1.js
```

You can also run each file in a browser console.
